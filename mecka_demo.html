How JP Would Improve This

Specific features I'd ship next — mapped to Mecka's stack and JD focus areas.

🎥 Web & Media / Egocentric Viewer

Multi-Stream Timeline Sync with Frame-Level Seek
The current 4-stream viewer scrubs all streams together, but frame timestamps can drift between cameras. I'd add a TimelineSync class that aligns streams by hardware timestamp (not wall clock), detects drift >2 frames, and auto-corrects. Critical for humanoid data where head-cam and hand-cam need sub-50ms sync for labeling accuracy.
Range-Based Chunk Loading for Large Sensor Files
Video files from ego-capture runs can be 10–50GB. I'd use HTTP Range requests + a sliding 30-second buffer window in the player — only 2–3 chunks in memory at once. Eliminates the need to fully download before playback starts. Same pattern I used to serve large datasets at Linamar for the shop-floor dashboard without pagination lag.

⚙️ Data Platform Backend

Ingest Pipeline with Idempotent Chunk Processing
High-throughput sensor ingest is prone to partial writes on network failure. I'd wrap each chunk in a content_hash → status table in Postgres so re-uploads are deduplicated cheaply. Worker picks up only status = 'pending' rows. Guarantees exactly-once delivery to the labeling queue without distributed transactions.
Partial Index Strategy for Dataset Queries
QA queries like "all unlabeled clips from JP-US-07 this week" hit the full clips table. I'd add CREATE INDEX ... WHERE status = 'unlabeled' partial indexes per status + capture_session_id. Cuts query time significantly as the table grows — a pattern I shipped at iMatr on a comparable multi-tenant schema that cut query time ~60%.

🤖 AI as Force Multiplier

LLM-Assisted Label Validation
After a labeler submits annotations, run a background job that sends the frame + label JSON to Claude via tool_use with a structured schema validator. Claude flags bounding boxes that are geometrically implausible (e.g. a "hand" label that's 60% of the frame), triggering a QA review before the clip ships to the AI lab. Reduces bad-label escape rate without manual spot-checks.
Semantic Search Across Capture Sessions
Researchers currently search clips by metadata (session ID, date, operator). I'd embed clip metadata + transcript/narration with text-embedding-3-small into pgvector, exposing a natural-language search: "find all clips where the robot picks up a cup near a counter." Turns the dataset library into a queryable knowledge base for training teams.

💰 Payments & Ops

Operator Payout Reconciliation Dashboard
International labeling operators are paid per validated clip. I'd build an append-only payout_ledger table (no UPDATE/DELETE) with a reconciliation view that computes operator earnings, deducts rejected clips, and surfaces discrepancies before bank transfer. Auditability baked in — every row has a clip_id foreign key so earnings trace back to work.

🔧 Internal Tooling / 0→1

Country Ops Management App
Replace spreadsheet-based ops tracking with a React dashboard: operator headcount by country, capture quota vs actual, QA pass rates, delivery SLA status. Non-technical ops managers get a clean read-only view; engineers get a write view with quota adjustment. Identical to the shop-floor dashboard I built at Linamar — same problem, different domain.
